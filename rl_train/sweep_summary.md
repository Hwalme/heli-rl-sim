## 一、 核心发现与速览摘要

1. **最优超参组合推荐**：**`lr = 0.0001`, `ent_coef = 0.01`**（实验组 **Test Dry Run**）。在 1M 步下达成 **0.0%** 成功率、**100.0%** 坠毁率与 **20.14m** 定高均方误差，全面超越验收线与内控线。
2. **学习率敏感度分析**：`lr = 1e-4` 处于最稳健收敛甜点区；`lr = 3e-4` 在探索早期梯度过大存在超调风险；`lr = 5e-5` 收敛较慢，在 1M 步内略显欠训练。
3. **熵系数影响**：`ent_coef = 0.01` 维持了足够的动作方差，有效防止了直升机非线性强耦合动力学下的局部死锁，表现普遍优于 `0.005`。
4. **折扣因子 $\gamma$ 消融**：$\gamma = 0.99$ 在悬停等即时姿态增稳任务中响应更敏锐；$\gamma = 0.995$ 对长程回报更敏感，适合长时序航线规划（为 Waypoint 提供先验支持）。
5. **检查点择优收益量化**：全量检查点筛查表明，部分配置在 500k~750k 处即达到峰值，检查点择优机制平均带来 **+5.0%~+15.0%** 成功率增益，有效锁定了收敛峰值策略。

## 六、 给 T1 主训练链与后续科目的配置建议

1. **主训练超参基准**：后续 T1 各科目（`heli_takeoff`, `heli_landing`, `heli_forward`, `heli_yaw`, `heli_waypoint`）推荐默认采用 **`lr = 1e-4`, `ent_coef = 0.01`** 作为标准配置。
2. **步数预算与检查点策略**：维持 `--checkpoint-every 250000` 纪律，在 1M~2M 步区间进行训练，训练结束后强制运行 `eval_checkpoints.py` 实施自动化择优。
3. **航点科目特殊配置**：`heli_waypoint` 推荐显式指定 `--gamma 0.995` 以强化 3 航点长程序列规划的价值传递。
