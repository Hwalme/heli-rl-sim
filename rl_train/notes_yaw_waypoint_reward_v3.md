## 2. 物理诊断（2026-08-29 探针实测，脚本 `rl_train/_probe_yaw_wp.py` / `_probe_yaw_dir.py`，原始输出 `logs/probe_yaw_wp_raw.log` / `logs/probe_yaw_dir_raw.log`）

### 2.1 【结构病灶】抗扭矩 trim 积分在回合内被冻结 → 残余左自旋不可镇定 → yaw 任务结构性不可解

- 基类 `_post_physics()`（jsbsim_tasks.py L262-266）的文档明确"抗扭矩积分 trim **每步推进**, 让策略可以利用 trim ... 故全程开放"，但 **6 个任务 step() 内没有任何一处调用它**——trim 只在 reset 的 `_fly_to_hover` 爬升段积分，回合开始后**冻结在爬升末态**（PD 爬升自旋 60°/s → trim 顶满 +0.7 饱和；悬停策略爬升亦为 +0.4~0.7 正值，见多任务训练报告"trim 从 0 增长到 0.413"）。
- `_apply_sas` 中 rud = u_yaw·0.3 + 0.4r − 0.15(coll−0.5) + **trim(+0.7)**，clip ±0.8——trim +0.7 直接把脚蹬基线顶到饱和区。
- **方向可行性探针**（trim 冻结 +0.7，30s 脚本扫描）：

| u_yaw | 稳态偏航速率 r |
|---|---|
| +1.0（满左舵） | **−46 dps** |
| 0 | −17 ~ −27 dps |
| −1.0（满右舵） | **−9 ~ −12 dps** |

  **任何脚蹬输入下 r 均为负（左转）**：满反舵只能把 −27 dps 减半到 −9 dps，正速率不可达。而 success 判定要求 5° 窗口内累计 2s（100 步）：以最快的 −9 dps 扫过 ±5° 窗口每次仅 1.1 s < 2 s——**该状态下任务数学上不可解**。这解释了 R7/R8 的 0% 与 94% 坠毁（策略为凑航向势函数差猛蹬舵 → 滚转耦合发散 → >60° 坠毁）。**这不是 reward 形状能修的**，必须先把 trim 积分在回合内接通（恢复基类钩子的文档语义），让 trim 可被策略利用着收敛残余自旋。
- waypoint 同样受害：回合内 trim 冻结 → 航向只会左转（~−20 dps），L 形航线随机方向意味着约一半几何**只能左转逼近**，配合滚转漂移（零动作实测漂到 −25°，超过 ~−30° 后基类 SAS 副翼权限不可恢复）→ 78% 坠毁、189 m 脱靶。
- 修复口径：仅在 **YawManeuverTask.step / WaypointTrackTask.step** 的 `self.fdm.run()` 之后补一行 `self._post_physics()`（task 级、逐行 `# v3:` 标注）。不动基类、不动其他任务通道、不动动作契约/观测/success 口径。此为本次改写唯一超出"纯 reward 块"的改动，属恢复基类钩子的既文档化语义（`_lock_yaw_trim` 测试接口保留未用），特此向 D/E 报备。

### 2.2 【reward 病灶】yaw v2 奖励的三个结构性缺陷

v2 奖励（jsbsim_tasks.py L668-675）：
```
r = 20*(prev_err − err)            # 航向势函数
  + 0.8*dir_sign*r                 # 速率塑形（无界、不随误差收敛）
  + (2.0 if on_hdg else −0.05)     # 带内
  − 0.05*alt_err − 0.05*(|θ|+|φ|) − 0.01Σa² − 50 坠毁
```
1. **速率塑形无界且在误差→0 仍满额支付**：`0.8·dir_sign·r` 在 90 dps 时 +1.26/步，转过头 sign 翻转继续付——等价于"转得越快越好"，鼓励穿靶旋转；高速旋转引发滚转耦合（探针：spin 中 roll 漂移加速），而姿态罚仅 0.05/rad（55° 时 −0.05/步），与 −50 坠毁一次性罚相比，"猛转-坠毁"轨迹的折扣回报优于"慢转-保持"→ PPO 收敛到野蛮旋转。**对照 roll_v2 成功配方**：`1.5·tanh(3·(ref−roll))·p` 有界且误差→0 支付→0，yaw v2 恰恰缺了 tanh 因子。
2. **高度通道无锚**：success 要求**末步** alt_err<3 m，而探针显示该机体的自然漂移是高度塌陷（17.9 m → 1.5~8.5 m，满舵旋转时 30s 掉到 1.5 m）；v2 只有 −0.05·alt_err 线性小罚与带内 −0.05，无高度势函数、无高度带收入——策略没有任何"回 20 m 并保持"的梯度。
3. **无速率护栏**：|r| 无任何上限代价（forward v3 的 (J) 超速护栏 / (K) 俯冲护栏在 yaw 的对偶物缺失）。

### 2.3 【reward 病灶】waypoint v2 奖励的三个结构性缺陷

v2 奖励（jsbsim_tasks.py L765-780）：
```
r = 8*(prev_dist − dist) − 0.05·alt_err − 0.05(|θ|+|φ|) − 0.01Σa² − 0.05
    − 0.5·dive(θ<−15°) + 30·到点 + 50·完成 − 0.5·(agl<1) − 50 坠毁
```
1. **进度势函数无速度护栏 → 冲速度吸引子**：8·Δdist 对任意接近方向/速度线性支付。探针（基类 SAS，u_pitch 恒定扫描）：u_pitch=+0.2 → 40 kt、+0.4 → 75 kt、+0.6 → 117 kt 且爬高到 100~300 m（拉力倾斜+阻力弱），与 forward v2"冲速度发散"同构；坠毁前每步净收入仍为正（30 m/s 时 A 项 +4.8/步 vs alt 罚 0.05·10=−0.5）→ 78% 坠毁是 reward 最优路径的产物。
2. **姿态/高度罚权重失衡 ~30 倍**：巡航 9 m/s 的进度收入 +1.44/步，而 55° 滚转仅罚 −0.05·0.96=−0.048/步——坠毁前的"野蛮但赚钱"状态无净负梯度；零动作基线会滚到 −25°（接近不可恢复边界）也只罚 −0.02/步。
3. **无接近漏斗/对准项**：10 m 到点半径在 189 m 脱靶下永远不会触发 +30；势函数只管"接近"，不管"对准"（朝向航点的航向误差无奖励），随机漂移与定向飞行在远场收入无差异 → 策略无理由学会转弯对准。
4. **（承接 2.1）trim 冻结使航向只左转**，航线几何一半不可达。

### 2.4 零动作基线账（v2 奖励下，30s/70s 回合）

- yaw 零动作：回合总奖励 −766（自旋漂移+高度塌陷），坠毁 0——不是趴地，是"漂着等死"。
- waypoint 零动作：回合总奖励 −2247（自然俯仰配平 −8~−9° → 漂到 17~19 kt、滚转 −25°、爬到 32 m），坠毁 0。**waypoint 的"不动"其实在前飞**——机体自带低头配平（fcs/adj/longitudinal-bias），所以 waypoint 不需要 forward 式的"生计奖励反趴地"，需要的是"把野蛮飞行变成受控飞行"。

## 3. v3 reward 数学形式（改动限于两个任务的 reward 块 + 各 1 行 trim 钩子接线）

### 3.0 公共先决（task 级结构修复，各 1 行）

```python
self.fdm.run()
self._post_physics()   # v3: 接通抗扭矩 trim 积分（基类钩子文档语义"每步推进/全程开放"）
```

### 3.1 yaw v3

记 `s_err = wrap(target_psi − ψ)`、`err = |s_err|`、`r` 为偏航角速率、`alt_err = |agl−20|`、`prev` 为上一步状态：

```
r_rew = 20.0*(prev_err − err)                          # (A) 航向势函数 [保留 v2]
      + 0.8*tanh(3.0*s_err)*r                          # (B) 有界速率塑形 [替换 0.8·dir_sign·r]
      − 1.0*max(0, |r| − 45°/s)                        # (C) 速率护栏 [新增]
      + (2.0 if err<5° else −0.05)                     # (D) 航向带 [保留 v2]
      + 1.0*(|prev_agl−20| − alt_err)                  # (E) 高度势函数 [新增]
      + (0.5 if alt_err<3 m else 0)                    # (F) 高度带 [新增]
      − 0.02*alt_err                                   # (G) 高度绝对小罚 [新增]
      − 0.05*(|θ|+|φ|)                                 # (H) 姿态小罚 [保留 v2]
      − 3.0*max(0, |φ| − 20°)                          # (I) 滚转护栏 [新增]
      − 3.0*max(0, |θ| − 15°)                          # (J) 俯仰护栏 [新增]
      − 0.01*Σa²                                       # (K) 动作能量 [保留 v2]
      − 50 (坠毁)                                      # (L) [保留 v2]
```

不动的东西：4 维动作契约、12 维观测、u_yaw 低通 τ=0.4s、success 判定口径（on_heading_steps>100 且末步 alt_err<3 且不坠毁）、回合长度 1500 步、目标 ±60~120° 均衡采样、trim 全程开放（R8 结论）。

| 项 | 意图 | 反 v2 病灶 |
|---|---|---|
| A | 保留因果梯度：每靠近 1 rad 立即 +20（全程机动总势差 21~42，一次性） | — |
| B | roll_v2 同款 tanh 有界速率塑形：机动中支付朝向目标的角速率、**误差→0 支付→0**（穿靶不再赚钱） | 病灶 1 |
| C | 45°/s 以上每 (rad/s) 罚 1.0：90 dps 净 −0.27/步、170 dps 净 −1.4/步，猛转严格劣于 5~20 dps 温转 | 病灶 3 |
| E/F/G | 高度三件套（forward v3 同构）：回 20 m 有势函数收入、带内 +0.5/步、偏差线性小罚——直接服务 success 的末步 alt 门槛 | 病灶 2 |
| I/J | 坠毁前渐进负梯度：滚转 20° 起坡、45° 时 −1.3/步、55° 时 −1.8/步 > 任何旋转收入 | 病灶 1 的坠毁路径 |

量级账（每步，50 Hz）：
- 到靶保持（err=0, r=0, alt=20）：2.0 + 0.5 − 0.05 − 0.01 ≈ **+2.44/步** → 剩余 ~1400 步 ≈ **+3400/回合**
- 机动段 20 dps 朝目标（err 60°）：+0.12(A) +0.28(B) −0.05(D) ≈ +0.35/步，另有到靶一次性势差 +21
- 猛转 90 dps：+0.52(A) +0.79(B) −0.79(C) ≈ +0.5/步，且穿靶后 A/B 反向、近靶时 B→0 而 C 仍罚 → 净负
- 接近坠毁（roll 50°）：−1.6/步，严格劣于保持态 +2.44
- 零动作（自旋 −25 dps + 高度塌陷）：≈ −0.3/步 → −450/回合，"漂着"严格劣于任何定向行为

### 3.2 waypoint v3

记 `dist`/`brg` 为到当前航点距离/方位（`_wp_rel` 不变）、`v_h = hypot(u, v)`（体轴速率模，旋转不变）、`alt_err = |agl−20|`：

```
r_rew = 8.0*(prev_dist − dist)                         # (A) 进度势函数 [保留 v2]
      + 0.6*clip(v_h/9.0, 0, 1)                        # (B) 巡航生计 [新增]: 9 m/s 饱和
      − 0.10                                           # (C) 拖延成本 [v2 的 0.05 → 0.10]
      + 0.3*cos(brg − ψ)                               # (D) 对准塑形 [新增]: 机头指向航点
      + (1.0 if dist<25 m 且 agl>3 m 且 未完)          # (E) 接近漏斗 [新增]: 到点前的密集引导
      + 30·到点 + 50·完成                               # (F) 航点奖 [保留 v2]
      + 1.0*(|prev_agl−20| − alt_err)                  # (G) 高度势函数 [新增]
      − 0.02*alt_err                                   # (H) 高度绝对小罚 [新增]
      − 0.05*(|θ|+|φ|)                                 # (I) 姿态小罚 [保留 v2]
      − 3.0*max(0, |φ| − 15°)                          # (J) 滚转护栏 [新增]
      − 3.0*max(0, |θ| − 15°)                          # (K) 俯仰护栏 [v2 的 0.5 单边 −15° → 3.0 双边]
      − 0.5*max(0, v_h − 12.5 m/s)                     # (L) 超速护栏 [新增]: 对偶 forward (J)
      − 1.0*(agl<3 m 且 steps>50)                      # (M) 低高度成本 [v2 的 0.5@1m → 1.0@3m]
      − 0.01*Σa²                                       # (N) 动作能量 [保留 v2]
      − 50 (坠毁)                                      # (O) [保留 v2]
```

不动的东西：4 维动作契约、13 维观测、航点几何（3 点 L 形 80 m）、到点半径 10 m、回合 3500 步、success 判定口径（3 点全到且不坠毁）、基类 SAS 执行包络。

| 项 | 意图 | 反 v2 病灶 |
|---|---|---|
| A | 保留接近的因果梯度 | — |
| B | 巡航存量收入：9 m/s（机体自然配平巡航 ~17-19 kt=8.7-9.8 m/s）即满额 +0.6，受控前飞每步为正 | 与 A 互补（forward v3 双结构验证过） |
| D | 对准收入 +0.3·cosΔ：远场就开始为"转弯朝航点"付费（补势函数只管接近不管对准） | 病灶 3 |
| E | 25 m 漏斗 +1.0/步：把 10 m 到点半径的稀疏 +30 变成可达梯度 | 病灶 3（189 m 脱靶） |
| G/H | 高度锚：防"冲速度-爬高-坠毁"与"下沉-接地"两条坠毁路径 | 病灶 1/2 |
| J/K | 渐进姿态护栏：>15° 起罚，45° 时 −1.6/步 > 巡航全部收入 | 病灶 2 |
| L | 12.5 m/s 以上每 (m/s) 罚 0.5：30 m/s 时净 −3.4/步，关闭"冲速度"吸引子 | 病灶 1 |
| M | 3 m 以下重罚：贴地不再廉价（agl<1 才罚 0.5 太松） | 边界情形 |

量级账（每步，50 Hz）：
- 受控巡航 9 m/s @20 m 对准：+1.44(A) +0.6(B) +0.3(D) −0.1(C) −0.06(H) −0.02(I) ≈ **+2.16/步**；漏斗内 +3.16
- 全任务：~300 m 航径 / 9 m/s ≈ 1650 步 ≈ **+3600 + 航点奖 140 ≈ +3700/回合** vs 坠毁路径（≤600 步 × <2 + 一次性 30）——生存压倒性优于坠毁
- 冲速度 30 m/s：+4.8(A) +0.6(B) −8.75(L) −高度项 ≈ **−3.4/步**，野蛮模式关闭
- 零动作漂移（9.5 m/s、滚转 −25°、缓慢爬高）：+1.5(A) +0.63(B) −0.52(J) −0.1(C) −高度漂移项 ≈ ~0/步且永远拿不到航点奖 → 严格劣于受控飞行，无趴地吸引子

## 4. 预期行为曲线（写于训练前，供事后对照）

- **yaw**：0~100k 冒烟——on_heading_steps/回合从 ~0 抬升、坠毁率显著下降（<30%）、末段航向误差从 ~80° 向下；300k 前 success 出现；500k 双门槛 ≥90%/0 坠毁。失败形态（若现）：末段航向误差卡在 20~40° 不再下降且 trim 长期贴 ±限（trim 收敛仍不足 → 需评估 reset 段 trim 预收敛，属结构二轮，先记录不盲动）；或 crash 率不降（护栏权重不足）。
- **waypoint**：0~100k——回合奖励从 ≈−2000 抬升、v_h 均值出现 5~12 m/s 受控段、坠毁率下降；200k 前首个航点开始被稳定到达（wp_idx 峰值 ≥1）；500k 双门槛 ≥90%/0 坠毁。失败形态：v_h 长期 <2 m/s（拖延主导 → 调 B/C 量级）或 alt 长期 >30 m（L/G 不足）。

## 5. 冒烟计划（每科目 ≤100k 步）

- `python train_jsbsim.py --task yaw --steps 100000 --seed 42 --n-envs 8 --eval-seeds 42 --model-path results/jsbsim_ppo_yaw_smoke_v3.zip`，日志 `logs/yaw_v3_smoke.log`；waypoint 同构。
- 冒烟判据（非验收）：奖励曲线有梯度（回合奖励均值相对 v2 明显抬升、无趴地/无锁死）、坠毁率显著低于 v2 同期、行为迹象（yaw：on_heading 步数>0 或末段误差 <50°；waypoint：出现 dist 单调下降段 / wp_idx≥1）。
- 内置 20 回合确定性评估在 100k 处**不作验收判据**（10% 训练量），仅看趋势。

## 6. 正式训练与验收

## 9. 【冒烟发现与第 1 轮内修订——waypoint】（2026-08-29 追记）

### 9.1 冒烟实测（100k，`logs/waypoint_v3_smoke.log` + 60k 复核 `logs/waypoint_v3_smoke2.log`）

- 坠毁率 78% → **0%**（护栏生效）；
- 但 ep_rew_mean 从 −18.3k 单调**下跌**至 −25k：策略落入"直线快飞（~25 m/s）远离航点"吸引子——
  机体自然低头配平 + 弱阻力使其一旦放弃姿态控制就以 25 m/s 直飞，而 v3 初版对准项 +0.3·cosΔ
  在 PPO ~6s 有效视野（γ=0.99, 回合 3500 步）内弱于超速罚的悬崖（25 m/s 时 −6.25/步），
  远场所有状态都被压到深负值，早期策略无处可爬。

### 9.2 修订（官方训练前完成，计第 1 轮内调整，4 处标量）

1. 对准塑形 0.3 → **0.8**·cosΔ（远场唯一航向信号，权重须在短视野内可见）；
2. 超速护栏斜率 0.5 → **0.25**（梯度而非悬崖：25 m/s 时 −3.1/步）；
3. 滚转护栏起坡 15° → **30°**（给压坡转弯留工作区——roll_v2 实证 15~20° 坡度可控，
   航点转弯的正确解法是压坡而不是只靠脚蹬），斜率 3.0 → **5.0**（45°/55° 逼近坠毁路径仍净负）；
4. 俯仰护栏斜率 3.0 → **5.0**（起坡 15° 不变，俯仰改平后巡航配平 −8° 在工作区）。

### 9.3 训练配置（同 yaw）

`--init-model results/jsbsim_ppo_direct.zip` 悬停课程初始化。冒烟对照：init=none 时
ep_rew 在 −18k~−25k 深负区打转；init=hover 起点即 −0.7k/回合（悬停保持态，坠毁 0），
问题从"活下来"降维为"学会转向航点"。

## 10. 【waypoint 第 1 轮实测与第 2 轮修订】（2026-08-29 追记）

### 10.1 第 1 轮正式结果（500k + 悬停课程，`logs/waypoint_v3_train.log`，2101 steps/s）

| 指标 | v2 (R8) | v3 第 1 轮 |
|---|---|---|
| 坠毁率 | 78% | 70% |
| 成功率 | 0% | 0% |
| 平均脱靶 | ~189 m | ~879 m |

训练期 ep_rew_mean 收敛到 −1.6k/回合（≈悬停保持态），但确定性评估 70% 坠毁、脱靶 879 m。

### 10.2 诊断："原地悬停农场"——短视野下的先亏后赚死锁

- 训练策略学会**悬停在原点**：无条件高度带 +0.5/步 + 对准项绕圈均值 ≈0 − 拖延 0.1 ≈
  **+0.3/步 零风险坐吃**；而"转向航点"动作先亏后赚——转向期间距离不降反可能升，
  对准/进度收入要等转弯完成后才开始，**γ=0.99 在 3500 步回合的有效视野只有 ~6s
  （0.99^300≈0.05），转弯的全部收益都在视野之外** → 转向永远不值得。这与 forward v2
  "趴地"完全同构：目标动作（转向）前期成本即时、回报滞后超视野。forward v3 的解药
  （低头塑形/生计奖励=立即为动作本身付费）在此缺位。
- 评估 70% 坠毁 vs 训练期存活：确定性动作使漂移不均化，姿态/高度缓慢发散超出护栏
  起坡线（悬停农场没有动力学习姿态保持——它连高度都只被动维持）。

### 10.3 第 2 轮修订（`# v3-r2:` 标注，2 个新增/修订项；本科目第 2 轮，若仍 0% 按红线止损）

```
(D2) 转向塑形 [新增]: +1.0·tanh(3·(brg−ψ))·r      # 立即为"朝航点方位的转动"付费
(F)  高度带 [新增+门控]: +0.5 if (alt_err<3 且 v_h>3 m/s)   # 悬停农场关闭
```

- D2 是 roll_v2 速率塑形 / yaw v3 (B) 项的直接移植（对偶关系：yaw 的 brg=目标航向固定，
  waypoint 的 brg=到航点方位随位置缓变）：压坡/蹬舵转向的每一步都有 +0.2~0.3/步 即时收入，
  转弯的"先亏后赚"变成"边转边赚"；对准后 tanh→0 自动退场，无自旋刷分空间。
- F 门控后悬停收入 ≈ +0.3−0.5 = **−0.2/步**，农场转负；真正巡航（9 m/s、20 m 高）
  收入升为 +2.16+0.5−0.1 ≈ +2.6/步。
- 证据留档：第 1 轮结果 copy 为 `results/jsbsim_ppo_waypoint_v3r1_results.json` / `_v3r1.zip` / `_v3r1_trajectory.json`。

### 10.4 第 2 轮正式结果与止损（2026-08-29）

- 实测（`logs/waypoint_v3r2_train.log`，2284 steps/s）：**0% 成功 / 60% 坠毁 / 平均脱靶 382 m**
  （seed42: 65%, 123: 65%, 7: 50%, 0: 55%, 99: 65%）。较第 1 轮（70% 坠毁/879 m）有改善
  （转向塑形确实让策略走得离航点更近），但成功率仍为 0%。
- **轮次对照**：

| 轮次 | reward 关键差异 | 成功率 | 坠毁率 | 脱靶 |
|---|---|---|---|---|
| v2 (R8 基线) | 进度势+弱罚 | 0% | 78% | 189 m |
| v3 r1 | +护栏/对准/漏斗/课程 | 0% | 70% | 879 m |
| v3 r2 | +转向塑形/高度带门控 | **0%** | 60% | 382 m |

- **🔴 红线触发：连续 2 轮改写 0% → waypoint 止损，不再第三次改写，证据交 E。**
- 止损归因（reward 已到边界，剩余为结构/物理层）：
  1. **航向控制通道权限不足是硬约束**：低转速下残余左自旋 −4~−27 dps 且脚蹬行程不对称
     （探针 §2.1），高转速下风标效应锁死航向（yaw r1 速度农场实证）——"精确指向 80 m 外

  3. 若后续重启，建议路径（供 E 方案 C 讨论参考，未经授权不执行）：
     a. 任务层口径：到点半径 10→30 m、或航点航线改为绕场航线（对航向精度要求降一个量级）；
     b. 训练层：γ=0.997 + 回合缩短到 1500 步 + 航点数 3→1 先学单点（课程分解）；
     c. 结构层：航向通道 SAS 重做（pedal-gain 提高 + trim 换向对称化）——超出 reward 改写
        授权范围，需 E 另行裁决（与 sim-state-schema/动作契约评审联动）。

3. 说明：配平收敛等价于飞行试验前"配平悬停检查点"——机动本身仍由 RL 策略完成；
