## 1. 动作空间定义

### 1.1 direct 模式（底层控制，已实现于 rl_train/helo_env.py，v1 不变）

动作向量：4 维，`[-1, 1]`：

| 索引 | 含义 | 解码 |
|------|------|------|
| 0 | 总距 | `collective = (a0 + 1) / 2 ∈ [0,1]` |
| 1 | 周期变距·俯仰 | 截断到 [-1,1] 直接使用 |
| 2 | 周期变距·滚转 | 同上 |
| 3 | 尾桨（踏板） | 同上 |

### 1.2 arm 模式（机械臂层，v1 正式定义）

动作向量：**7 维归一化关节目标角** `j = [j0..j6]`，每个分量 ∈ `[-1.5, 1.5]`，单位 **unit**（无量纲行程坐标）。

语义：`j_i` 是"目标角"，经 §3.3 延迟 + §3.2 速率限制 + 内部 P 控制器（增益 `2.0 /s`）追踪；实际关节角再经 §4 映射产生直升机 4 维控制量。

| 分量 | 操纵通道 | 备注 |
|------|---------|------|
| j0 | 总距 collective | 唯一双满程通道（[0,1] 全程） |
| j1 | 周期变距·俯仰 | 线性有效区 \|j1\| ≤ 0.8，之外饱和 |
| j2 | 周期变距·滚转 | 同上 |
| j3 | 尾桨（踏板） | 同上 |
| j4–j6 | **预留** | v1 不接入映射，冻结为 0；为腕部/末端功能保留 |

## 2. 归一化关节坐标与 URDF 关节的对应

- 契约层一切数值使用归一化坐标 `j ∈ [-1.5, 1.5]`。
- 物理执行层（PyBullet KUKA iiwa URDF，7 转动关节）每个真实关节 `q ∈ [q_lower, q_upper]`（单位 rad，以 URDF 声明为准，**不得硬编码**）。
- 两层按**线性满程**一一对应：`q = q_mid + (j / 1.5) · q_half`，其中 `q_mid = (q_lower+q_upper)/2`，`q_half = (q_upper−q_lower)/2`。即 `j=−1.5 ↔ q_lower`，`j=0 ↔ q_mid`，`j=+1.5 ↔ q_upper`。
- 内置 `kuka_iiwa/model.urdf` 的限位实测（自检 T1，运行时从 URDF 读取）：j0 ±2.967、j1 ±2.094、j2 ±2.967、j3 ±2.094、j4 ±2.967、j5 ±2.094、j6 ±3.054 rad。
- 真实臂型号替换时仅更换 URDF 与标定参数（§7），本节映射关系不变。

## 3. 正式化条款（v1 新增）

### 3.1 机械限位与安全软限位

| 层级 | 范围（unit） | 执行点 | 违反时行为 |
|------|-------------|--------|-----------|
| 硬限位（机械） | `[−1.5, +1.5]` | 映射计算前强制 clip | 数值不可能越界；URDF 层由 `q_lower/q_upper` 兜底 |
| 软限位（安全） | j0: `±1.5`（不收紧）；j1–j6: `±1.45` | `set_target` 目标层钳位 | 钳位到软限位 + 记录 `soft_limit` 告警 |

设计理由：
- **j0 不收紧**：collective 满程（0/1）要求 j0 触达 ±1.5，收紧会损失升力行程。
- **j1–j6 收紧到 1.45**：这些通道线性有效区只有 |j| ≤ 0.8（§4），1.45 已深度饱和，收紧无功能损失，保留的 0.05 余量用于异常检测带（见 `arm/safety.md` §3）。

### 3.2 关节角速率上限

- **全部关节**：`|ĵ| ≤ 1.5 unit/s`（v1 缺省值，标定可按关节覆盖为标量数组）。
- 实现位置：P 控制器输出 `ĵ_des = 2.0·(j* − j)` 之后**先钳位再积分**。
- 物理含义：匀速段全行程（3 unit）最快 1.0 s；因 P 控制器指数尾段，99% 行程实测 ≈ 2.5 s（自检 T3b）。
- 数值量级对齐 KUKA iiwa14 手册 A1–A3 ≈ 85°/s ≈ 1.48 rad/s；真实臂标定后按 §7 覆盖。
- 消费方影响：RL 动作不再被理解为瞬时可达，大跨度目标角存在确定的执行包络（利于 sim-to-real）。

### 3.3 控制延迟模型

v1 定义两档，缺省 **L1**：

| 档 | 模型 | 行为 |
|----|------|------|
| L0（遗留） | 无延迟 | 目标即时生效，等价 v0 行为（`helo_env.py` 现状） |
| **L1（v1 缺省）** | `hold_steps` 个控制周期**零阶保持** + 一阶跟踪 | 新目标延迟 1 个控制周期生效；跟踪 `ĵ = 2.0·(j* − j)`，等效时间常数 `τ_eq = 1/2.0 = 0.5 s` |

- 延迟以**控制周期数**计（与频率解耦）：`rl_train` arm 模式 DT=0.02 s（50 Hz）→ 延迟 20 ms；`helo_sim_final` 演示环 DT=0.01 s（100 Hz）→ 延迟 10 ms。
- 两个参数（`hold_steps`、跟踪增益）均为标定项（§7），缺省 `hold_steps=1`、增益 `2.0 /s`。

### 3.4 急停语义（详细触发条件与异常检测见 `arm/safety.md`）

| 级别 | 名称 | 关节目标 | P 增益 | 映射输出覆盖 |
|------|------|---------|--------|-------------|
| ESD-L1 | 软停 | 冻结为当前关节角 | 2.0（不变） | 无覆盖（保持当前输出） |
| ESD-L2 | 硬停 | 冻结为当前关节角 | **0.5**（降级） | **`(collective_当前, 0, 0, 0)`**：总距保持防瞬间掉高，姿态/航向指令归零 |
| ESD-L3 | 预留 | — | — | 预留（自转着陆等，真实臂阶段定义） |

- **生效时机**：急停置位后**下一控制周期**生效（最坏 ≤ 1 个 DT）；激活期间一切新目标被拒绝并告警。
- **解除**：仅允许显式 `clear_estop()`，且前提是全部关节回到软限位内；解除后目标从中位/当前角重新建立（参考实现：目标=当前角）。
- 直升机侧兜底不在本契约范围（机体失联保护由 A/B 轨道环境层负责）。

### 3.5 真实臂标定流程（占位，型号确定后执行）

1. **数据采集**：从真实臂 URDF/手册读取关节限位、最大角速率、额定力矩。
2. **延迟辨识**：空载阶跃试验，拟合 `hold_steps`（传输+解码延迟）与一阶时间常数 `τ`。
3. **映射标定**：对 j0–j3 各通道做标定台试验，拟合增益/偏置/死区（缺省无死区）。
4. **参数落档**：全部覆盖项写入 `arm/calibration.yaml`（schema 见 §7），参考实现加载后覆盖缺省值。
5. **回归验证**：重跑 `python arm/kuka_iiwa_model.py` 自检 + A 轨道 heuristic 回归，确认映射输出与 §4 一致。

## 4. 关节 → 操纵映射（公式冻结，与既有实现逐字一致）

对实际关节角（归一化坐标）`j = [j0..j6]`：

```
collective      = clip((j0 + 1.5) / 3.0,  0, 1)
cyclic_pitch    = clip(j1 / 0.8, -1, 1)
cyclic_roll     = clip(j2 / 0.8, -1, 1)
pedals          = clip(j3 / 0.8, -1, 1)
j4..j6          不接入（预留）
```

- 来源：`helo_sim_final.py` L193–203；`rl_train/helo_env.py` `_arm_to_controls()` 与之相同。
- **饱和语义**：j1–j3 在 |j| > 0.8 后输出饱和于 ±1，不再增加操纵量（RL 需知此非对称有效区）；j0 无饱和（±1.5 全程线性对应 collective 0→1）。
- 中位语义：全零关节角 → `(0.5, 0, 0, 0)`（地面上总距 0.5 ≠ 悬停推力，悬停 collective 由机体模型决定，rl_train 中 ≈ 0.7014）。
- 急停 L2 时本映射输出被覆盖（§3.4），覆盖发生在映射之后。

## 5. 数据类型与单位约定

| 量 | 类型 | 单位 |
|----|------|------|
| 动作向量 / 关节角（契约层） | `float32`（gym）/ `float64`（内部） | unit（无量纲） |
| URDF 关节角 | `float64` | rad |
| 关节速率 | `float64` | unit/s（契约层）、rad/s（URDF 层） |
| 控制量输出 | `float` ×4 | 无量纲（collective [0,1]，其余 [-1,1]） |
| 控制周期 DT | `float` | s（消费方时钟，rl_train=0.02） |
