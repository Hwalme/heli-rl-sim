## 4. 通信架构分析（为什么必须内环在 FG 里）

| 架构 | 实测带宽 | 结论 |
|---|---|---|
| v1：telnet 逐属性（每帧 10 get + 3 set） | **≈6.6 s/帧（0.15Hz）**，单次往返 0.4~0.5s | Bo-105 悬停增稳需要 ≥10Hz（诊断报告 §1.2 要求控制周期 ≤0.1s），差 66 倍。离地即发散，不可救 |
| v2：Nasal 内环（FG 进程内 ~60Hz）+ Python 低频目标（~3Hz telnet） | 内环若活，带宽足够 | **当前路线**。卡点只剩"Nasal 定时器不跑"，见 §5/§6 |
| 备选：UDP generic 双向 | 未验证 | 需写正确的 protocol XML。注意诊断报告 §1.3 否定的是"无协议文件的裸 UDP 文本"，generic 本身没被否定。这是 Nasal 路线彻底失败时的 fallback |

v2 客户端（现 `fg_demo.py`）已经就绪并经过一次真机飞行（19:09）：自检、agl 基准校准、总距斜坡+PI、状态机、坠机判别、日志落盘全部工作正常。**它不需要再改**（除非换符号标定流程）。

## 5. FG 2024.1.4 本机构建的 Nasal/XML 全部坑（踩一遍的代价，接手者直接背下来）

1. **XML 注释里禁止 `--`**（包括在注释里写 `--config=xxx` 这种"示例"）。解析器报 `not well-formed (invalid token)`。
2. **Nasal 不支持 `%` 运算符**：`me.frame % 60` → `parse error: illegal character`（两次独立启动在同一行复现）。取模用 `math.mod`（官方代码用法；但见第 5 条疑点）。
3. **Nasal 读未声明的哈希成员会抛异常，不是返回 nil**：`me.hz_cnt == nil` 这种"防御式判断"本身就是致死点 → `Nasal runtime error: No such member: hz_cnt`。所有 `me.xxx` 必须在哈希字面量里声明初值，或用局部 `var`。
4. **`/orientation/*-rate-deg` 不存在**，正确是 `-rate-degps`。`/sim/time/elapsed-time` 也不存在（`(unknown)`），用 `/sim/time/elapsed-sec`。
5. **疑点未结**：rev3c 声明 hz_cnt 后仍死且**日志零报错**。未能排除 `math.mod` 在内环命名空间同样 `No such member`（emexec/geo 在全局命名空间用它是加载期引用，不代表运行期可用），以及重复错误是否被日志限流。**rev4 已设计为完全不依赖 math.mod / dt / counter / 未声明成员**，就是为了绕开全部疑点。
6. **`maketimer` 未见成功先例**（本会话里它从未跑到过第一拍之后的证据）。rev4 改用 `settimer(loop, 0)` 帧驱动——这是 FG 最古老的惯用法，bo105.nas 自身也用 settimer，理论上必活。
7. **telnet props 协议不支持 `run <nasal>`**：发出去不执行也无报错。无法交互调试 Nasal，只能"改 XML → 重启 → 看日志/属性"循环。
8. Nasal 解析错误行号**含 CDATA 头部偏移**，与文件行号对不上；真实报错行内容会打在日志下一行（`NasalSys.cxx:1710: <code>`），以那个为准。
9. 机型 Nasal 加载成功的标志是日志里出现脚本自己的 print（如 `=== DemoStab rev4 loaded ===`）；**出现这行不代表循环能跑**，必须用 ticks 属性验证。

### telnet 探针（读属性/写属性/liveness 测试）
```python
import socket, time, re
s = socket.create_connection(('127.0.0.1', 5501), timeout=10)
s.settimeout(2.0); time.sleep(0.3)
def rd():
    out = b''
    while True:
        try: c = s.recv(65536)
        except socket.timeout: break
        if not c: break
        out += c
        if out.rstrip().endswith(b'>'): break
    return out.decode('utf-8','replace')
rd()
def get(p):
    s.sendall(f'get {p}\r\n'.encode()); time.sleep(0.1)
    m = re.findall(r"'([^']*)'", rd())
    v = m[-1].strip() if m else '?'
    if v.lower()=='true': return 1.0
    if v.lower()=='false': return 0.0
    try: return float(v)
    except: return 0.0
def setp(p, v):
    s.sendall(f'set {p} {v}\r\n'.encode()); time.sleep(0.1); rd()
```
