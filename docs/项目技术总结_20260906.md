### 2.2 致命缺陷链（9/5 补审，8 组探针）
1. **速率传感器全死**：`velocities/{p,q,r}-radps` 恒 0.0000（脉冲响应实测）。后果：AFCS 内 `-2.5p/-2.5q/-2.87r` 三个阻尼通道全部失效；
2. **气动零阻尼**：无阻尼力矩项 → 俯仰/滚转是无阻尼发散模态，实测离地后发散速率 ~500°/s 量级（1 秒内多圈翻滚）；
3. **根因定位**：自定义 root 下 run_ic 阶段速率节点未注册（1.3.1 惰性创建 + XML 先引用）——helispike.xml 头注释自证"rate damping lives in the probe harness SAS"；
4. **连带假阳性**：8/30 SPIKE 探针判据 `peak_yawr_dps<5` 读到的就是死值 0.0 → 平凡通过；952ft/60s 爬升不合 180hp 物理量级。

## 3. 修复工程：D3 串级 SAS（本项目核心技术成果）

### 3.1 设计（契约 D3 "SAS 内环 + RL 外环"的落地形态）

```
RL 策略 (50Hz) 输出 4 维:
  u_coll  → 总距直接通道: coll = clip(0.70 + u_coll*0.20, 0, 1)
  u_pitch → 姿态目标: cmd_pitch = ±12° * u_pitch        (外环, 指令)
  u_roll  → 姿态目标: cmd_roll  = ±12° * u_roll          (外环, 指令)
  u_yaw   → 偏航速率: ±0.25 归一化脚蹬

SAS 内环 (200Hz 物理率, 每个子步):
  roll_err = phi_rad − cmd_roll
  pitch_err = theta_rad − cmd_pitch
  ail = clip( −40·roll_err − 0.05·p_diff , ±0.30)      ← 滚转负反馈
  ele = clip( +40·pitch_err − 0.05·q_diff , ±0.42)     ← 俯仰正反馈
  rud = clip( +0.08·hdg_err + cmd_yaw_rate , ±0.60)
  其中 p_diff/q_diff = 姿态差分重建速率 (绕开死传感器)
```

### 3.2 标定依据（每一条都有实验出处）
| 设计量 | 值 | 出处 |
|---|---|---|
| 姿态符号 | +aileron→phi 增(恢复取负)；+elevator→theta 减(恢复取正) | 静态阶跃标定 `_e_sign/_e_ailsign/_e_coll_vz` |
| K_ATT=40 | 网格扫描：k≥10 全稳定，40-60 最优(max|att| 9.5-10.4°)；k≤5 不稳 | `_e_sas_grid.py` + `_e_sas_refine.py` |
| K_RATE=0.05 | 速率项必须极小：大 K_RATE 增加相位滞后反而翻覆(kd≥2 全灭) | 同上网格 |
| 高度环 K_ALT=0.25 / K_VS=0.010 | d(vz)/d(coll)≈52 决定积分增益必须 ~0.01 量级，否则 1 秒内总距打穿限幅振荡 | `_e_coll_vz.py` |
| CMD_ATT_MAX=±12° | 外环权限上限，防策略一步打满 | 工程选择 |
| 交接协议 | spool→495RPM(dt=0.01, cap 40s) → 爬升至目标高度+垂速收敛(|vz|<0.5, |Δalt|<2m) 才交棒；健康门=姿态<MAX_ANG+RPM 带 | `_e_reset_probe.py` 5 种子全过 |

### 3.3 验证结果
- 物理：60s 浸泡 max|att| 9.6°、vz −0.03m/s；0.5s 满副翼扰动 5s 内恢复（`_e_sas_refine.py`）；
- 交接：5 种子 handover phi≤0.3°/theta≤4.8°/vz≤0.5m/s；
- 训练：300k 步 **42%→复评 45% 成功 / 0% 坠毁 / 1.79m**（5 种子×20 回合；对比修复前恒 0%/100%）；训练吞吐 **742 steps/s**（4 envs CPU）。

## 5. 训练系统技术档案

### 5.1 环境规格（helispike_env.HelispikeHoverEnv）
- 物理 200Hz（dt=0.005）× ACTION_REPEAT=4 → 控制 50Hz（0.02s/步）；
- 回合 20s = 1000 控制步；观测 12 维（agl/50, vz/15, u,v/15, pitch/MAX_ANG, q/2, roll/MAX_ANG, p/2, r/2, alt_err/50, pos_n/50, pos_e/50，全部 nan_to_num+clip±10）；
- 动作 4 维 [-1,1]（coll/pitch/roll/yaw，经 §3 串级映射）；
- 奖励：`2.0·Δalt_err(进度) − 0.3·(|θ|+|φ|) − 0.01·Σa² − 0.1·grounded + hover_bonus(2.0/0.8) + 0.1 − 0.1·v_horiz − 0.02·drift − 50·crash`；

## 6. FlightGear 演示链技术档案（B 轨）

- **版本坑**：FG 2024.1.4 —— `--disable-full-screen` 已废弃（弹框中止）；telnet 通道不接受末尾 `,prompt`（6 段式 `socket,in,5,127.0.0.1,5501,tcp`）；输出重定向需 `--console=0`；
- **地形坑**：fgdata 内置仅冰岛+夏威夷，KSFO 无地形直接沉地——演示机场定 PHNL（tile w158n21）；
- **bo105 绑定**：总距绑 throttle **反向**（0=满距）；功率杆 0.63=慢车/1.0=飞行位；governor 稳态 ≈428RPM（非文档 442）；
- **telnet 闭环判死**：13 次往返/帧 × 0.4-0.5s = 6.6s/帧（0.15Hz），距 10Hz 控制带宽差 66 倍 → 架构性不可用；
- **Nasal 9 坑表**：`%` 运算符非法（用 math.mod）、角速度属性是 `-degps` 后缀、未声明哈希成员抛异常、elapsed-time 不存在、settimer 帧驱动自调度可行、生命体征属性（/demo/stabilizer/ticks）模式有效；rev4 内环 E 亲测 25.7Hz ALIVE；
- **进程管理**：bash 后台任务会随会话被连带杀（三次"离奇消失"真相）；`explorer.exe` 不代理 bat；Git Bash 会转换 `--prop:/...` 路径；**WMI/CIM 创建是唯一可靠方式**；
- **终局架构**：JSBSim 权威 + `fdm=null` 显示壳 + playback 回放 + G4 质量闸门（因 B-Shell 曾出现"判据错位"：回放轨迹漂移 138m/航向转 90° 未被发现）。

## 9. 技术债务与开放问题（按优先级）

1. **p/q/r-radps 根治**：env 层差分重建是 workaround；正解是在 FDM XML 里按 al3.xml 的 E0PROPS 模式预注册速率节点，让 XML 级阻尼复活（评估后决定是否值得做——env 层已够用）；
2. **2M 步全量训练**：300k→45%，85% 线需 2M+（可能叠加奖励微调：drift/高度项权重）；
3. **二代任务族展开**：heli_takeoff/landing/forward env 类已就绪（SAS 已内置），各需先过 30k 探针；
4. **AG-2 口径澄清**（需求方）：仿真时长是否计入 1000h、同策略重复采集有效性、二代机型数据与一代口径的关系；
5. **git 卫生**：历史中 203MB docx（仓库膨胀）；`.gitignore` 应纳入 `_e_*` 输出类产物；
6. **AG-3 无效数据归档**：6 组 0%/100% sweep 已标注无效，防止未来误引用；
7. **多机 spread**：当前单机 20 核 CPU 足够 hover 族，landing/waypoint 长视野任务可能需要并行机或云端 GPU（与 C 轨共用申请）。

## 10. 技术一句话

**这架自研直升机"飞不起来"的原因不在奖励、不在超参、甚至不在控制律，而在"传感器的腿是瘸的"**——先用姿态差分把速率传感重建（绕开死腿），再按 D3 契约把 SAS 内环装回 200Hz 物理率、把策略从"直接打舵"升格为"下姿态指令"，训练当夜就从 0%/100% 坠毁变成 45%/0% 的真悬停。剩下的 85% 验收线，是算力与时间问题，不再是物理问题。
