## 关键结论（实验/自检记录）

1. 内置 `kuka_iiwa/model.urdf` 7 关节限位实测（rad）：±2.967 / ±2.094 / ±2.967 / ±2.094 / ±2.967 / ±2.094 / ±3.054，URDF 声明速度上限 10 rad/s（手册值 ~1.5 rad/s，故速率限制由契约层钳位而非依赖 URDF）。
2. 速率钳位 1.5 unit/s 下，P 控制器（增益 2.0）阶跃轨迹为两段式：匀速段（diff>0.75）+ 指数尾段，99% 全行程 ≈ 2.44 s（自检 T3b）。
3. 硬停（ESD-L2）实测：关节零漂移、输出覆盖 `(collective_保持, 0, 0, 0)`，激活期新目标被拒（自检 T5）。
4. 控制延迟 L1（hold_steps=1）在 50 Hz 下 = 20 ms 指令延迟，可复现验证（自检 T4）。
5. D4 技能库：到位判定采用"容差带内稳定保持 0.3 s"（首次入带即判会产生 ~0.017 collective 稳态偏差）；按压/旋钮类末端技能对操纵通道（j0–j3）零扰动；急停期间序列立即中止并报告 skipped_esd。
