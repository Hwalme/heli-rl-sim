## 1. 目的与范围

### 1.1 目的

将 B4 座舱三维资产（操纵机构几何）转化为机械臂操控链路的**可标定动力学参数**，使 `arm/calibration.yaml`（action-space §7 schema）从占位变为真实参数，支撑 sim-to-real 迁移与验收指标"操控映射准确率 ≥90%"的真实环境复验。

### 1.2 范围

- **在范围内**：机械臂本体参数辨识（关节限位/速率/力矩/延迟）、操纵通道映射标定（增益/偏置/死区）、座舱操纵量程→归一化系数接口。
- **不在范围内**：座舱三维建模本身（B4 轨道）、飞行器动力学辨识（A/B 轨道）、真实臂验收选型（E/需求方）。

### 1.3 前置依赖

| 依赖项 | 提供方 | 状态 | 阻塞程度 |

## 3. 辨识什么参数（calibration.yaml 字段全覆盖）

对应 `interfaces/action-space.md` §7 schema，全部参数需从仿真缺省值替换为真实测量值。

### 3.1 机械臂本体参数（真实臂阶段）

| 参数 | 缺省值（KUKA iiwa SIL） | 辨识方法 | 精度目标 |
|------|----------------------|---------|---------|
| `joint_limits_soft` [7] | [1.50, 1.45×6] unit | URDF 读取 + 实测软限位触发点 | ≤ ±0.01 unit |
| `joint_rate_max` | 1.5 unit/s（标量，可扩为数组） | 空载阶跃试验：阶跃 0→1.0 unit，测 10%→90% 上升时间，拟合最大速率 | ≤ ±5% |
| `control.hold_steps` | 1（控制周期） | 指令下发→关节开始运动的延迟测量（高速相机/编码器时间戳） | ≤ ±1 周期 |
| `control.p_gain` | 2.0 /s | 阶跃响应拟合：过调量/上升时间反推 P 增益 | ≤ ±10% |
| `control.tau_eq` | 0.5 s | 阶跃响应 63.2% 到达时间 | ≤ ±10% |
| `esd.gain_degraded` | 0.5 | 急停激活后 P 增益实测 | ≤ ±10% |
| 电机额定力矩/峰值力矩 | — | 手册/铭牌 | 逐字记录 |

### 3.2 操纵通道映射参数（座舱几何驱动）

| 参数 | 缺省值 | 辨识方法 | 精度目标 |
|------|--------|---------|---------|
| `mapping_gain` [4] | [1.0, 1.0, 1.0, 1.0] | 标定台试验：机械臂末端推操纵杆至各行程点，记录关节角→操纵量，线性拟合增益 | ≤ ±2% |
| `mapping_bias` [4] | [0.0, 0.0, 0.0, 0.0] | 同上，拟合截距（中立点偏移） | ≤ ±0.01（归一化） |
| `mapping_deadzone` [4] | [0.0, 0.0, 0.0, 0.0] | 小信号试验：关节角从 0 缓慢增加，记录操纵量开始变化的阈值 | ≤ ±0.01（归一化） |

### 3.3 座舱量程→归一化系数（B4-D 接口核心）

契约 §4 的映射公式假设 j0 ∈ [-1.5, 1.5] → collective ∈ [0, 1]。真实座舱中，总距杆全行程 L_col 对应 collective 0→1，因此：

```
j0_normalized = (握把位置 - 最低位置) / L_col × 3.0 - 1.5
```

同理 j1/j2/j3 的归一化系数 = 2.0 / 各通道全行程（unit/mm）。

**这些系数由 B4 几何测量结果计算，D 评审后写入 calibration.yaml 的 `mapping_gain`。**

## 4. 辨识方法与试验设计

### 4.1 阶段一：空载本体辨识（机械臂独立，不需要座舱）

| 试验 | 方法 | 输出 | 预计耗时 |
|------|------|------|---------|
| T1 关节限位读取 | URDF 解析 + 手动推至限位触发急停 | `joint_limits_soft` | 1h |
| T2 速率阶跃 | 每关节 0→±1.0 unit 阶跃，50Hz 记录编码器，10 次/关节取均值 | `joint_rate_max` | 2h |
| T3 延迟测量 | 指令时间戳 vs 编码器首次运动时间戳（高速相机 100fps 同步） | `hold_steps` | 2h |
| T4 P 增益/时间常数 | 阶跃响应曲线拟合（过调量 + 上升时间） | `p_gain`, `tau_eq` | 2h |
| T5 急停验证 | ESD-L2 激活后测增益降级 + 输出覆盖 | `gain_degraded` | 1h |

### 4.2 阶段二：操纵通道映射标定（机械臂 + 座舱，需 B4 资产）

| 试验 | 方法 | 输出 | 预计耗时 |
|------|------|------|---------|
| T6 量程标定 | 机械臂推总距杆从最低到最高，记录关节角 vs 操纵杆位移（光栅尺/视觉标记），5 次取均值 | j0 `mapping_gain/bias` | 3h |
| T7 周期杆标定 | 俯仰/滚转方向分别推至满行程，同上 | j1/j2 `mapping_gain/bias` | 4h |
| T8 脚蹬标定 | 左右脚蹬分别推至满行程 | j3 `mapping_gain/bias` | 2h |
| T9 死区测量 | 每通道从 0 缓慢增加关节角，记录操纵量首次偏离中立点的阈值 | `mapping_deadzone` | 2h |
| T10 全行程线性度 | 每通道 10 个等间距点，测实际操纵量 vs 理论值，R² ≥ 0.99 | 线性度报告 | 3h |

### 4.3 阶段三：带载/动力学辨识（可选，B4 Q3 答复"需要"时执行）

| 试验 | 方法 | 输出 |
|------|------|------|
| T11 操纵力测量 | 机械臂以恒定速率推操纵杆，记录关节力矩（电流估算或力矩传感器） | 摩擦/阻尼系数 |
| T12 回中特性 | 释放操纵杆，记录自由回中轨迹（位置-时间） | 弹簧刚度/阻尼 |

### 4.4 阶段四：回归验证（辨识完成后）

- 重跑 `python arm/kuka_iiwa_model.py` 自检（22/22），确认标定参数下契约行为不变；
- 重跑 `python arm/eval_skills.py`（125 回合），确认技能库在真实参数下成功率 ≥90%；
- 与 A 轨道联合做 heuristic 回归（机械臂→操纵→JSBSim 悬停），确认端到端映射无系统性偏差。

## 5. 精度目标汇总

| 类别 | 参数 | 精度目标 | 依据 |
|------|------|---------|------|
| 几何 | 操纵机构尺寸 | ≤ ±1 mm | B4 提案 §3 关键尺寸 ≤±5mm，D 加严 |
| 几何 | 限位角度 | ≤ ±0.5° | 契约软限位 0.05 unit 余量 |
| 本体 | 关节速率 | ≤ ±5% | 速率钳位是安全包络核心 |
| 本体 | 控制延迟 | ≤ ±1 周期（20ms@50Hz） | 契约 §3.3 L1 定义 |
| 本体 | P 增益/τ | ≤ ±10% | 执行包络仿真精度 |
| 映射 | gain/bias | ≤ ±2% / ±0.01 | 验收指标"操控映射 ≥90%"的误差预算分配 |
| 映射 | 死区 | ≤ ±0.01（归一化） | 小信号操控精度 |
| 映射 | 全行程线性度 | R² ≥ 0.99 | 线性映射假设的有效性验证 |
| 端到端 | 技能执行成功率 | ≥90%（验收线），内控 ≥95% | 验收指标 4 |

## 6. 与 B4 的接口约定

1. **数据格式**：B4 交付座舱模型时，同步交付 `platform/b4_cockpit_assets/calibration_inputs.yaml`，含 §2.2 全部运动学参数（数值 + 测量方法 + 测量人员 + 日期）。
2. **评审节点**：D 收到 B4 标定输入后 3 个工作日内完成评审，确认量程/中立点/限位与契约假设一致；不一致则出差异工单（mailbox-E）。
3. **变更流程**：座舱几何若发生设计变更（如总距杆行程调整），B4 须提前通知 D，D 重新评估 mapping_gain 是否需要更新，走 action-space 契约变更流程。
4. **联合测量**：T6-T10 标定试验需 B4 提供座舱实物或 1:1 工装，D 负责机械臂操作与数据采集，双方联合签字确认。
